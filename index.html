NFC · Del mundo digital al físico

Un tag del tamaño de una moneda que conecta lo físico con internet

Un chip NFC no tiene batería, no necesita app y no ocupa espacio. Acercas el teléfono y pasa algo. Conectado a una web con base de datos, cada toque puede contar, registrar o llevar a la persona justo a donde tiene que ir.

# Todo corre sobre Ubuntu

        
Todos mis proyectos los construyo en Linux. Algunas extensiones GNOME que uso para volver locas las pantallas (y a veces literalmente quemarlas un poco):

        
    
          
  • Burn My Windows — transiciones de ventana exageradas al cerrar/abrir apps.
    • 
          
  • Blur My Shell — desenfoque dinámico en toda la interfaz.
    • 
          
  • Compiz-style Wobbly Windows — ventanas que se mueven como gelatina.
    • 
        

        
¿Por qué Linux y no Windows para esto? Porque el kernel es abierto: puedes cambiarlo. Mainline, Liquorix, Xanmod, Zen — cada uno prioriza algo distinto (latencia, throughput, eficiencia), y tú eliges. En Windows el kernel es una caja cerrada; en Linux es una pieza más que puedes intercambiar según lo que necesites.
